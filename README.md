This repository contains the STICS soil-crop model input and output files, including the simulation units, parameter files, plant files, and associated files used to perform the simulations presented in the following study:

Agbohessou, Y., Falconnier, G. N., Justes, E., Diop, S., Civil, J.-A., Couëdel, A., Shumba, A., Corbeels, M., Chikowo, R., Six, J., Thierfelder, C., & Cardinael, R. Evaluation of the STICS soil-crop model to simulate N2O emissions and their drivers in conventional and conservation agriculture in Zimbabwe
